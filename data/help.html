The window

The list at the top shows every partition. The bottom part shows each disk as a bar, with its partitions drawn to size. Blue means a partition, grey means free (unallocated) space. A lock on a disk means your system is running from it, so DiskForge won't change it.

Right-click anything to see what you can do with it. Double-click a mounted drive to open it in your file manager.

How to

Use a USB stick: plug it in, right-click it, Mount, then Open in File Manager. Unmount it before you pull it out.

Format: right-click the partition, Format. Everything on it gets erased.

New partition: right-click grey unallocated space, New Partition. A brand new disk needs a partition table first (right-click the disk on the left, New Partition Table).

Resize: right-click the partition, Resize. It can only grow into free space right after it. exFAT can't be resized, XFS can only grow. Back up anything important first.

Rename: select it and press F2.

Delete: right-click, Delete Partition. The space becomes unallocated.

Make a USB stick from an ISO: File → Write Image to USB. Pick the ISO and the stick, type the stick's name to confirm. Paste the SHA-256 from the download page if you have it, so a broken download is caught before anything is written. Works for Linux ISOs; Windows ISOs need a tool like WoeUSB.

Unplug a USB drive: right-click the disk on the left, Safely Remove. Everything gets unmounted and the drive is powered off, so it's safe to pull out.

Check for errors: right-click the partition, Check for Errors. If problems are found, DiskForge offers to repair them.

Mount a drive every time the PC starts: right-click the partition and tick Mount at Startup. It will show up under /mnt.

Encrypt a drive: tick "Encrypt with a passphrase" when you format or create a partition. To use it later, right-click it and Unlock, then Mount. Lock it when you're done.

Open an ISO or disk image: File → Open Disk Image (Ctrl+O). It shows up as a disk you can mount and browse. Close it from the disk's right-click menu.

Is my drive OK? The dot on each disk shows its health: green is fine, orange means it's wearing out (keep backups), red means back it up now. Right-click the disk, Disk Health for details and self-tests. USB sticks don't report health.

How fast is it? Right-click the disk, Benchmark. Reading doesn't change anything; the optional write test uses a temporary file.

Wipe a whole disk: right-click the disk on the left, Wipe Disk. Every byte is overwritten with zeros. Do this before you sell or give away a drive.

Start a disk over: right-click the disk on the left, New Partition Table. You have to type the disk name to confirm. Pick GPT unless it's for a really old computer.

Add-ons: Tools → Add-ons lets you install extra actions other people made, like backing up a drive or opening a terminal in it. They show up in the right-click menu and the Tools menu. The first time one runs, DiskForge shows exactly what it will run and asks first. Only install add-ons you trust.

Which file system?

  • exFAT: USB sticks and external drives, works on Windows, Mac and Linux (needs exfatprogs)
  • FAT32: old devices and boot sticks, but no files over 4 GB
  • NTFS: drives you also use with Windows
  • ext4: Linux-only drives
  • btrfs: Linux with snapshots, at least 256 MB
  • XFS: Linux, big files, can't shrink (needs xfsprogs)

Problems

Something is greyed out: hover over it in the Action menu to see why.

"Not authorized": the password prompt was cancelled, or there's no polkit agent running.

"Device or resource busy": something still has files open on the drive. Close it and try again.

A drive is missing: press F5. Empty card readers are hidden.

Still stuck? Open an issue at github.com/DannyS124/diskforge/issues and paste the output of diskforge --dump.

Shortcuts

F1 help, F2 rename, F5 refresh, Ctrl+O open disk image, Delete delete partition, Alt+Enter properties, Ctrl+Q quit.
