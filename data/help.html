The window

The list at the top shows every partition. The bottom part shows each disk as a bar, with its partitions drawn to size. Blue means a partition, grey means free (unallocated) space. A lock on a disk means your system is running from it, so DiskForge won't change it.

Right-click anything to see what you can do with it. Double-click a mounted drive to open it in your file manager.

How to

Use a USB stick: plug it in, right-click it, Mount, then Open in File Manager. Unmount it before you pull it out.

Format: right-click the partition, Format. Everything on it gets erased.

New partition: right-click grey unallocated space, New Partition. A brand new disk needs a partition table first (right-click the disk on the left, New Partition Table).

Resize: right-click the partition, Resize. It can only grow into free space right after it. exFAT can't be resized, XFS can only grow. Back up anything important first.

Rename: select it and press F2.

Delete: right-click, Delete Partition. The space becomes unallocated.

Make a USB stick from an ISO: File → Write Image to USB. Pick the ISO and the stick, type the stick's name to confirm. Paste the SHA-256 from the download page if you have it, so a broken download is caught before anything is written. Works for Linux ISOs; Windows ISOs need a tool like WoeUSB.

Unplug a USB drive: right-click the disk on the left, Safely Remove. Everything gets unmounted and the drive is powered off, so it's safe to pull out.

Check for errors: right-click the partition, Check for Errors. If problems are found, DiskForge offers to repair them.

Mount a drive every time the PC starts: right-click the partition and tick Mount at Startup. It will show up under /mnt.

Encrypt a drive: tick "Encrypt with a passphrase" when you format or create a partition. To use it later, right-click it and Unlock, then Mount. Lock it when you're done.

Open an ISO or disk image: File → Open Disk Image (Ctrl+O). It shows up as a disk you can mount and browse. Close it from the disk's right-click menu.

Is my drive OK? The dot on each disk shows its health: green is fine, orange means it's wearing out (keep backups), red means back it up now. Right-click the disk, Disk Health for details and self-tests. USB sticks don't report health.

Bad sectors: right-click the drive, Scan for Bad Sectors. The scan reads everything and changes nothing. If it finds unreadable sectors, Repair rewrites just those: whatever still reads is kept, the rest was already lost. The drive then reuses each spot or swaps in a spare. The "reallocated" count in Disk Health never goes back down; that's normal. If new bad sectors keep appearing, the drive is wearing out.

While it scans, a map of the drive fills in: green reads fine, orange is slow, red can't be read. Hover over a square to see where it is. Slow spots often turn into bad sectors later, so keep a backup of that drive.

Get files off a dying drive: right-click the drive, Rescue Copy. It copies everything that can still be read into an image file (or onto another drive): the easy parts first, then it goes back for the hard ones. You can stop it and start it again later with the same file; it carries on where it stopped. Do this before running any repairs on a failing drive. Then open the image with File → Open Disk Image and copy your files off.

Copy a whole drive: right-click the drive, Clone Drive, for example to move to a bigger SSD. Empty space isn't copied, and on a bigger drive the last partition can grow into the extra space. Pick "replaces the old drive" if the old one is going away (it's an exact copy), or "keep using both" so the copy gets its own IDs. You can't clone the drive you're running from; start from a live USB for that.

Back up a drive or partition: right-click it, Back Up. It's saved as one compressed .img.zst file with a small .json next to it. Keep both. Empty space packs down to almost nothing. Save it on a different drive.

Put a backup back: right-click the drive or partition, Restore Backup, and pick the .img.zst. The whole backup is checked against its checksum before anything is written, so a damaged file can't half-overwrite your drive.

What's using all the space? Right-click a mounted partition, Disk Usage. Big boxes are big folders; click one to look inside. Folders you can't open (other users', the system's) aren't counted.

Free up space: Tools → Disk Cleanup. It removes old package files, packages you've uninstalled, old system logs, your cache folder and the trash. It shows how much each one frees first. On Btrfs with snapshots, the space only comes back once the old snapshots are gone.

Keep an SSD fast: Tools → Optimize Drives. It tells the SSD which space is free (TRIM). Tick "every week" and you don't have to think about it again. Hard drives don't need it, and Linux doesn't need defragmenting.

Snapshots: Tools → Btrfs Snapshots lists your Btrfs subvolumes and the snapshots snapper took (before and after each pacman update, for example). To go back to one, use snapper or the snapshot entries in your boot menu.

Erase an SSD properly: right-click the drive, Secure Erase. The drive erases itself, including spare areas that Wipe Disk can't reach. If it says the drive is frozen, click Sleep Now, wake the PC up, then Check Again. Keep the PC on until it's done.

How fast is it? Right-click the disk, Benchmark. Reading doesn't change anything; the optional write test uses a temporary file.

Wipe a whole disk: right-click the disk on the left, Wipe Disk. Every byte is overwritten with zeros. Do this before you sell or give away a drive.

Start a disk over: right-click the disk on the left, New Partition Table. You have to type the disk name to confirm. Pick GPT unless it's for a really old computer.

Add-ons: Tools → Add-ons → Get Add-ons lists add-ons you can install, or use Install from File for one you have. They add extra actions, like backing up a drive or opening a terminal in it. They show up in the right-click menu and the Tools menu. Before one runs, DiskForge shows exactly what it will run and asks. Ones that use admin power (pkexec, sudo) or run a shell ask every time. Look-only add-ons run in a sandbox where they can't change anything, and they're the only ones offered for the disk your system runs from. An add-on that turns up without being installed through DiskForge is marked "Added outside": if you didn't put it there, remove it. Only install add-ons you trust.

Which file system?

  • exFAT: USB sticks and external drives, works on Windows, Mac and Linux (needs exfatprogs)
  • FAT32: old devices and boot sticks, but no files over 4 GB
  • NTFS: drives you also use with Windows
  • ext4: Linux-only drives
  • btrfs: Linux with snapshots, at least 256 MB
  • XFS: Linux, big files, can't shrink (needs xfsprogs)

Problems

Something is greyed out: hover over it in the Action menu to see why.

"Not authorized": the password prompt was cancelled, or there's no polkit agent running.

"Device or resource busy": something still has files open on the drive. Close it and try again.

A drive is missing: press F5. Empty card readers are hidden.

A Secure Erase got cut off and now the drive is locked: during the erase the drive has the temporary password xxxx. Unlock it with sudo hdparm --user-master u --security-unlock xxxx /dev/sdX, then sudo hdparm --user-master u --security-disable xxxx /dev/sdX (use your drive's name), and run the erase again.

Using the Flatpak? Disk Usage only sees your home folder, /run/media and /mnt, and add-ons need one extra permission: flatpak override --user --talk-name=org.freedesktop.Flatpak io.github.DannyS124.DiskForge. The Arch package doesn't have these limits.

Still stuck? Open an issue at github.com/DannyS124/diskforge/issues and paste the output of diskforge --dump.

Shortcuts

F1 help, F2 rename, F5 refresh, Ctrl+O open disk image, Delete delete partition, Alt+Enter properties, Ctrl+Q quit.
