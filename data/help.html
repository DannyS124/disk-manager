The window

Volume list (top). Every partition on every disk, with its label, device name (/dev/sdb1), file system, status, size and free space. Free space is only shown for mounted volumes.

Disk map (bottom). One row per disk. The box on the left shows the disk number, its partition table (GPT or MBR), the connection (NVMe, SSD, HDD, USB), its size, and whether it's Online or a locked System disk. To the right, each partition is drawn as a block:

  • a blue bar on top means a partition
  • a grey bar means unallocated space you can use for a new partition
  • a striped block is the current selection

Click anything to select it. Selecting in the list selects it in the map, and the other way round. Right-click for everything you can do with it. Double-click a mounted volume to open it in the file manager. Hover over a block for details.

Common tasks

Use a USB stick

Plug it in and it appears by itself. Right-click its partition and choose Mount, then Open in File Manager. Choose Unmount before pulling it out.

Format a drive

Right-click the partition and choose Format…. Pick a label and a file system (see Choosing a file system). The dialog says exactly what will be erased and asks again before it starts. A mounted partition is unmounted first.

Make a new partition

Right-click a grey Unallocated block and choose New Partition…. Set the size (all free space by default), a label and a file system. A brand-new disk with no partition table needs New Partition Table… first.

Shrink or grow a partition

Right-click the partition and choose Resize…. The dialog shows how much is in use and how far it can shrink or grow. Growing only uses unallocated space directly after the partition. ext4, Btrfs, NTFS and FAT32 can be resized; XFS can only grow; exFAT can't be resized at all. The app mounts or unmounts the partition first if its file system needs that. Back up anything important before resizing.

Rename a partition

Select it and press F2, or right-click and choose Change Label….

Delete a partition

Right-click and choose Delete Partition…. Everything on it is lost; the space becomes unallocated.

Start a disk over

Right-click the disk's box on the left and choose New Partition Table…. This erases every partition on the disk, so you have to type the disk's name (for example sdb) to confirm. Choose GPT unless the disk is for a very old computer or device, then MBR.

A file system whose tool isn't installed is greyed out in the list, with the package to install.

Safety

  • Your system disk is locked. Any disk holding the running system (anything mounted outside /run/media, /media or /mnt, or active swap) shows a lock and can't be changed. The check happens twice: in the window and again before any request is sent.
  • Changes need your password. DiskForge runs as you, not as root. Every change goes through UDisks2, the system disk service, which asks for your password through polkit.
  • Cancel is always the default button. Destructive buttons have to be clicked on purpose.
  • Ventoy sticks get a warning before any change that would stop them from booting.
  • Only one change runs at a time. Actions are greyed out until it finishes.

Troubleshooting

An action is greyed out. Hover over it in the Action menu for the reason, for example a system disk, a change still running, a file system that can't resize, or no free space after the partition.

"Not authorized". The password prompt was cancelled, or no polkit agent is running. KDE Plasma and GNOME include one.

"Device or resource busy". Something is still using the drive. Close file manager windows, terminals or programs that have files open on it, then try again.

A drive doesn't show up. Press F5 to refresh. Card readers and optical drives without media are hidden.

exFAT or XFS is greyed out. Install the tool shown next to it, for example sudo pacman -S exfatprogs.

Command line

diskforge --dump prints the disk layout as text, which is useful in bug reports. diskforge --select /dev/sdb1 starts with a partition selected. See man diskforge for all options.

Getting help

Report bugs or ask questions at github.com/DannyS124/diskforge/issues. Include the output of diskforge --dump.
